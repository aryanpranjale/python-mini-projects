# True/False Quiz Game 

A simple command-line quiz game built using Python and Object-Oriented Programming (OOP).

## Features
- 20 True/False questions.
- Accepts answers in different formats (`True`, `False`, `T`, `F`).
- Validates user input.
- Checks answers and updates the score.
- Displays the final score after completing the quiz.

## Project Structure

```text
Quiz_Game/
│
├── data.py             # Stores the list of questions
├── question_model.py   # Defines the QuestionModel class
├── quiz_brain.py       # Handles quiz logic and scoring
└── main.py             # Runs the quiz
```
